# 참고 이미지 분류

- `approved/`: 사용자 채택 방향. `five-staff-unlikable-approved.png`가 최신 5인 외형.
- `concept-wip/`: 다음 단계 제작의 출발점. 김 팀장 v1 시트는 엄격한 직교·A포즈가 아니므로 설계도 v2 필요.
- `exploration/`: 초기 시안과 사용자 기각 실사풍 자료. 게임 모델 제작 기준으로 사용하지 않는다.
- `office-caricature-approved.png`: 기존 v0.2.2 소스에 포함된 기준 아트 (경로 유지).

그림에 글자·스티커 메모가 그려져 있더라도 게임 대사의 공식 문안으로 자동 채택하지 않는다.
