# 프로젝트 코드/아트 배포 라이선스 상태

**프로젝트 자체의 공개/재배포 라이선스는 사용자가 아직 결정하지 않았다.** 따라서 임의로 MIT/CC0/CC-BY를 적용하지 않는다. 새 GitHub repository는 private으로 만들도록 안내한다. 이 README는 법률 자문이 아니다.

엔진/폰트 등 포함 외부 요소의 기존 라이선스는 `licenses/` 및 `licenses/SOURCES.md`를 따른다. 대화 중 생성한 콘셉트 이미지도 별도 출처·사용 조건을 확인하고, 타인의 지식재산권을 침해하는 모델·텍스처·애니메이션을 무단 유입하지 않는다.

향후 게임 출시/아트 외주/에셋 마켓 구매 시 각 파일의 출처, 상업적 사용 가능 여부, 재배포/수정 권한을 `docs/art/REFERENCE-MANIFEST.md`와 함께 관리한다.
