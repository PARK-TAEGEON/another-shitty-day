These fonts are the SIL Open Font License 1.1 files used by the 2026-11-19 UI.
Each OFL-*.txt is the license shipped with that family in the Google Fonts repository.
NotoSerifKR-Bold.ttf and NotoSerifKR-Black.ttf are static instances (weight 700 and 900)
of the OFL variable font Noto Serif KR. Do not remove the license files when copying the fonts.
