# 제작 로드맵 · 사람 검수는 중요 지점에만

| 단계 | 에이전트 산출물 | 자동·기술 검사 | 사용자 검수 게이트 |
|---|---|---|---|
| **R0 완료** | v0.2.2 원본 + 결정 기록 + 승인된 콘셉트 + 모션 연구를 로컬 Git repo에 보관 | 원본 파일/ZIP/참조 경로 검사 | 추가 플레이 검수 불필요 |
| R1 **김 팀장 v2 설계도** | 정면/측면/후면의 정확한 직교 A포즈, 표정·의상·손·색 분해 | 같은 치수·관절선·시점 일치 | **그림체/비율 승인** |
| R2 **게임용 메시·리그** | 김 팀장 `.blend`, `.glb`, 리깅, 표정, 걷기/빼꼼/꾸짖기 | 바인드/관절 스킨 변형 테스트, 파일 재수입 | 인게임 실제 회전·동작 검수 |
| R3 **래그돌 실험실** | 작은 피격 애니메이션 + 강한 충격 래그돌 + 누운 자세 | 접촉 방향, 관절 한계, 질량, 떨림, 프레임 수 | **타격감/넘어지는 코미디 검수** |
| R4 **사무실 소품 충돌** | 의자·책상·소품에 부딪히는 반응, 비용 중복 방지 | 충돌·가림·길찾기·성능 회귀 | 짧은 샌드박스 플레이 |
| R5 **나머지 네 직원 확장** | 공통 뼈대 규격 유지, 체형별 충돌체·표정·개성화 | 모든 배역 동작/피격 회귀 | **5인 장면 최종 스타일 검수** |
| R6 **통합·Windows 빌드** | 실내 공간과 NPC·경비 전체 연출, 최적화 | 본편 회귀 + native Windows + 5판 반복 | 제품 품질·재미 최종 검수 |

**예상 작업 순서에 대한 제안**이지 일정이나 자동 미래 실행 약속이 아니다.

## 에이전트 협업 프로토콜

- 구현자: 1개 milestone 단위로 코드를 수정하고, 소스·결과 캡처·검사 로그를 남긴다.
- 리뷰어: 동작이 아니라 성공했다고 주장한 내용을 실제 렌더/수치로 대조한다.
- 통합자: 결정 로그와 충돌 없이 메인에 합친다. 작업별 Git 브랜치와 PR을 사용하는 것은 GitHub 생성 후 시작한다.
- 사람: 대량 승인 대신 R1/R3/R5의 핵심 장면을 실제 눈과 손으로 판단한다. 심각한 오류가 있으면 특정 단계에서 재검수한다.

## 하지 않을 일

- 도면만 보고 “실제 모델 제작 완료”라고 보고하지 않는다.
- AI 생성 프리뷰를 그대로 3D 게임 모델로 취급하지 않는다.
- 물리 테스트장 성공 없이 5명 전체에 래그돌을 복제하지 않는다.
- 사무실 구조 A/B/C는 선택 전이므로 임의로 변경하지 않는다.
