# HIT-001 타격감 증거

로컬 Godot 4.7.2, Jolt, `task/hit-001`. 화면은 Linux llvmpipe 렌더다. Windows 손맛 승인은 아니다.

| 파일 | 내용 |
|---|---|
| `punch-stagger.png` | 펀치 한 대. 김 팀장은 서 있고 자막은 `꾸엑! 뭐, 뭐야!` |
| `kick-fly.png` | 발차기 포물선 중간. 몸이 바닥에서 떨어져 수평으로 날아감 |
| `kick-impact.png` | 그 궤적 끝에서 책상에 부딪힌 프레임 |
| `kick-wall.png` | 동쪽 벽 바로 앞에서 멈춰 벽에 붙은 장면 |
| `kick-desk.png` | 책상 모서리에 몸통이 걸린 장면 |
| `kick-launch.mp4` / `kick-launch.gif` | 같은 발차기 |

비행 구간은 스크립트 포물선이다. 그 동안 시뮬레이트된 몸 속도는 0이라 `kim_rig`의 속력 30 한도는 바꾸지 않았다. 충돌은 비행이 끝난 뒤 다시 켜진다.

## 튜닝 기본값 (`game/resources/hit_feel.tres`)

| 값 | 기본 |
|---|---|
| 펀치 힘 / 띄우기 | 7 / 2 |
| 발차기 힘 / 띄우기 | 13 / 2 |
| 비행 거리 / 높이 / 시간 | 4.5m / 1.45m / 0.70초 (0.10초 뒤 시작) |
| 몸 최고 속력 | 16 |
| 날아가는 동안 관절 배율 | 1.28 |
| 두 번째 타격 창 | 0.75초 |
| 히트스톱 / 슬로모 배율 / 슬로모 | 0.045초 / 0.36 / 0.16초 |
| 흔들림 펀치 / 날아감 / 충돌 | 0.62 / 1.05 / 0.85 |
| 충돌 튕김 | 0.16 |
| 비틀거림 대사 | 꾸엑! 뭐, 뭐야! |
| 래그돌 없는 발사 속력 / 위력 / 튕김 | 5.6 / 2.3 / 1.7 |

피해액 장부(치료 300000, 업무 200000)와 점수·별 규칙은 그대로다. 김 팀장 한 대 발차기 비교(`--kim-health-only`, `--kim-legacy`)도 유지한다.
