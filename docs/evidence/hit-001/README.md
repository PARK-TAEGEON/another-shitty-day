# HIT-001 타격감 증거

로컬 Godot 4.7.2, Jolt, `task/hit-001`. 화면은 Linux llvmpipe 렌더다. Windows 손맛 승인은 아니다.

| 파일 | 내용 |
|---|---|
| `punch-stagger.png` | 펀치 한 대. 김 팀장은 서 있고 자막은 `꾸엑! 뭐, 뭐야!` |
| `kick-fly.png` | 발차기 뒤 통로를 따라 밀려 넘어진 프레임 |
| `kick-impact.png` | 접촉음이 난 프레임. 팔이 들린 채 넘어가는 순간 |
| `kick-launch.mp4` / `kick-launch.gif` | 그 발차기 약 4초 |

기본 발사 속도는 `kim_rig`가 책상 접촉과 몸 속력 30 미만을 유지하도록 잡아 두었다. F8 슬라이더에서 `날아가는 속력`과 `날아가는 위력`을 올리면 더 뜬다. 그 손맛은 사람이 봐야 한다.

## 튜닝 기본값 (`game/resources/hit_feel.tres`)

| 값 | 기본 |
|---|---|
| 펀치 힘 / 띄우기 | 7 / 2 |
| 발차기 힘 / 띄우기 | 13 / 2 |
| 몸통 날아가는 속력 / 위력 | 8.0 / 4.2 (맞은 뒤 0.10초) |
| 몸 최고 속력 | 16 |
| 날아가는 동안 관절 배율 | 1.28 |
| 두 번째 타격 창 | 0.75초 |
| 히트스톱 / 슬로모 배율 / 슬로모 | 0.045초 / 0.36 / 0.16초 |
| 흔들림 펀치 / 날아감 / 충돌 | 0.62 / 1.05 / 0.85 |
| 충돌 튕김 | 0.16 |
| 비틀거림 대사 | 꾸엑! 뭐, 뭐야! |
| 래그돌 없는 발사 속력 / 위력 / 튕김 | 5.6 / 2.3 / 1.7 |

피해액 장부(치료 300000, 업무 200000)와 점수·별 규칙은 그대로다. 김 팀장 한 대 발차기 비교(`--kim-health-only`, `--kim-legacy`)도 유지한다.
