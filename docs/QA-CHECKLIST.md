# 테스트·검수 체크리스트

## 보존 회귀

- [ ] F 최초 입력: 박 대리가 놀라며 “왜 그래?”
- [ ] 김 팀장이 가림막에서 얼굴을 내밀고 짧은 길로 접근, 멈춘 뒤 잔소리
- [ ] 첫 샷건은 B, 반복 조작은 A; 양손 좌우/주먹 위치 정상
- [ ] 같은 부서 5명(여성 2명)과 타 부서 2명, 경비·경찰 대응이 유지
- [ ] UI 누적 피해액 `$`, 피격/충돌 불필요한 글자 없음, Esc 조작법 탭
- [ ] 피해액 차액만 추가, 여러 번 동일 대상 타격 시 중복 비용 금지
- [ ] 시점 조작·NPC 도중 타격·일시정지·재시작에서도 남은 예약 대사 취소

## 3D 아트/물리 게이트

- [ ] 얼굴 실루엣이 승인된 풍자 만화 스타일을 유지
- [ ] A포즈 바인드/팔·무릎·목 회전에서 부위 관통/늘어짐 없음
- [ ] 약한 타격은 휘청임만, 강한 충격은 방향성 있는 낙하
- [ ] 래그돌이 바닥/책상/의자와 충돌하고 비정상적 관절 꺾임 없음
- [ ] 낙하 안정 후 떨림/텔레포트 없음, 복귀를 구현했다면 전환이 자연스러움
- [ ] 동시에 다수 NPC가 넘어질 때 물리 지연과 5회 연속 플레이 확인

## 빌드 상태 보고 규칙

`headless 검사`, `실제 화면 캡처`, `Godot Windows export`, `Windows 네이티브 실행`, `사용자 손맛 검수`는 서로 다른 항목이다. 실행하지 않은 것을 통과했다고 주장하지 않는다.
