# DESK BREAKER — 채택 시안의 캐릭터 제작 기준

상태: **2026-10-11 사용자 채택.** [풍자 만화형 외형 시안](../art/references/office-caricature-approved.png)을 3D 제작의 기준으로 사용한다. 앞선 사실적 외형 A/B는 미채택이다. v0.1.1에서 상사·동료의 절차적 첫 3D 표현과 양손·첫 반응을 실제 게임에 연결했다. 아래 기준은 최종 모델과 동작의 품질을 계속 판단하는 데 사용하며, 현재 적용·검증 범위는 [현재 상태](current-status.md)에 기록한다. 공통 규칙은 [아트 방향](art-direction.md)을 따른다.

## 1. 이미지에서 유지할 특징

| 대상 | 실제 보이는 특징과 유지 기준 |
|---|---|
| **상사** | 넓은 어깨와 큰 배, 굵은 목, 앞으로 나온 넓은 턱. 큰 코·두꺼운 눈썹·반쯤 내려간 눈꺼풀로 못마땅한 인상을 만든다. 짧고 각진 검은 머리, 소매를 걷은 아이보리 셔츠, 황토색 넥타이, 짙은 바지와 벨트. 한 손은 허리에, 다른 손은 서류철을 쥔 자세를 기준 포즈로 삼는다. |
| **동료** | 상사와 대비되는 마른 몸, 길고 좁은 얼굴과 코, 도드라진 귀, 위로 뻗은 각진 머리. 검은 사각 안경과 비대칭 눈썹, 벌어진 입으로 지침과 당황을 드러낸다. 청록색 셔츠, 걷은 소매, 느슨한 짙은 넥타이. 의자 등받이에 팔을 걸치고 몸을 기울인 자세를 유지한다. **동료의 가는 팔까지 상사처럼 두껍게 통일하지 않는다.** |
| **1인칭 손·팔** | 화면 아래의 두툼한 주먹과 짧게 보이는 전완, 밝은 셔츠 소매. 손가락이 모여 하나의 주먹 덩어리로 읽히고, 손목은 손보다 가늘다. 피부는 단순한 따뜻한 색으로 정리한다. 왼쪽에는 왼손, 오른쪽에는 오른손이 자연스럽게 이어져야 한다. |

공통 미술 언어는 **과장된 성인 체형, 큰 면으로 정리한 얼굴과 옷 주름, 덩어리진 머리카락, 무광에 가까운 표면**이다. 이미지의 조명과 미세한 질감까지 재현하기보다 실루엣·표정·색의 관계를 먼저 맞춘다. 상사의 넓고 무거운 형태와 동료의 가늘고 기울어진 형태가 한 화면에서 구별되어야 한다.

## 2. 제작 순서와 첫 반응 장면

첫 제작 묶음은 **상사 1명·동료 1명·플레이어 양손**이다. 경비·경찰 등 추가 인물은 이 세 대상에서 미술 규칙을 확인한 뒤 확장한다.

1. **형태와 카메라 배치:** 기존 사무실의 책상 앞에 두 NPC와 손을 놓고, 시안과 비슷한 앉은 시점에서 머리·몸·손의 크기 관계를 맞춘다. 얼굴 세부 작업 전에 상사와 동료의 실루엣을 비교한다.
2. **얼굴과 손의 변형 준비:** 눈꺼풀·눈썹·입, 목·어깨·팔꿈치, 손목·엄지가 필요한 자세를 만들 수 있도록 구성한다. 구체적인 리깅 방식과 뼈 수는 모델을 보고 정한다.
3. **짧은 상황 시연:** D013에서 사용자가 지정한 아래 반응과 대사를 한 장면에서 이어 보여준다. 동작의 순서는 채택 사항이며 세부 타이밍과 소품 반응은 구현 후 화면으로 조정한다.
4. **게임에 통합:** 표현을 확인한 모델과 동작을 실제 입력·NPC 상태·충돌 시점에 연결하고, 기존 반응 및 프레임 비용을 확인한다.

| 대상 | 첫 시연에 필요한 최소 표정·동작 |
|---|---|
| 상사 | **건너편 가림막 뒤에서 업무 → 얼굴을 먼저 빼꼼 내밀며 “뭐야 무슨 소리야?” → “이게 무슨 짓이지?”라고 하며 플레이어 쪽으로 접근.** 얼굴이 드러나는 순간에는 눈·눈썹·입이 보여야 한다. 넓은 체형을 유지하면서 목·상체의 기울임과 가림막 높이로 머리부터 나타나는 동작을 만든다. |
| 동료 | **바로 근처에서 업무 → 충격에 손과 어깨가 움찔하며 하던 일을 멈춤 → 눈을 휘둥그레 뜨고 플레이어를 보며 “왜 그래?”**. 지친 기본 표정에서 눈꺼풀이 크게 열리고 눈썹이 올라가며 당황하는 변화를 보여준다. 안경테가 눈의 변화를 가리지 않게 확인한다. |
| 양손 | 느슨한 대기 → 주먹을 쥠 → 책상 내려치기 → 회수. **처음 감정이 터지는 연출은 B, 반복 조작은 A**라는 채택 방향을 유지한다. 짧은 팔 인상과 올바른 좌우·엄지 방향을 함께 확인한다. |

첫 배치는 플레이어의 책상 옆 가까운 곳에 동료를 두고, 건너편 가림막 뒤에 상사를 둔다. 기준 이미지의 상사 전신 포즈는 외형 확인용으로 유지하되, **D013의 시작 장면에서는 가림막이 상사를 가리고 얼굴이 먼저 나타나야 한다.** 상사는 가림막을 통과하지 않고 돌아서 접근한다. 동료의 큰 눈과 상사의 얼굴을 평소 플레이 시야각에서도 구별할 수 있도록 거리·높이를 조정한다.

충격 기준 동료 대사 약 0.25초, 상사 얼굴 등장 약 1.4초·첫 대사 약 1.85초, 항의와 접근 약 3.8초는 **초기 제작 제안**이다. 눈과 고개가 먼저 반응하고 몸과 대사가 뒤따르는 순서, 서로 겹치지 않는 대사 간격을 실제 렌더에서 맞춘다.

이 반응은 한 판의 첫 유효한 책상 내려치기에 한 번 연결하고, 행동 가능한 인물의 구간만 재생한다. 플레이어는 계속 이동·시점·행동을 조작한다. 반복 내려치기로 같은 대사를 되풀이하지 않으며, 관련 인물이 맞거나 쓰러지면 그 인물의 동작과 예약 대사를 중단한다. 피격 후 움찔함·뒷걸음·균형 상실은 별도 반응으로 이어지게 하며, 서류·안경·넥타이·의자가 뒤따르는 동작은 제작 제안으로 둔다.

대사는 **화자 이름 + 크고 대비 높은 글자 + 충분히 불투명한 어두운 배경**의 HUD 자막으로 한 번에 하나씩 표시한다. 자막 위치가 얼굴·손의 핵심 동작을 가리지 않고, 시점을 돌려도 읽히는지 확인한다. 대사 녹음 방식은 별도 미결정 사항이다.

피격은 충격과 균형 상실이 분명하게 읽히도록 만든다. 표정이 튀고 안경·넥타이·서류·의자가 엉키는 슬랩스틱을 중심으로, 성인 직장인이라는 인상을 유지한다. 사실적인 상처나 고통의 묘사를 외형 완성도의 기준으로 삼지 않는다.

### v0.2.1의 실제 메시 보강

다섯 직원의 얼굴을 같은 몸에 색만 다르게 적용한 인상에서 더 구분되도록 다듬었다. 김 팀장의 넓게 이어지는 턱, 박 대리의 길고 좁은 얼굴, 이 사원의 각진 윤곽, 최 과장의 짧고 넓은 얼굴과 후퇴한 헤어라인, 정 인턴의 좁은 턱을 각각 구성했다. 눈은 얕은 형태와 따라 움직이는 눈꺼풀로 정리하고 코·귀·헤어·깃·넥타이·셔츠 안쪽 면을 보강했다.

`tools/capture_character_lineup.gd`에서 같은 카메라·조명으로 실제 게임 모델을 전후 촬영한다. 이 검수용 줄 세우기 장면은 평상시 게임 배치와 구분한다. 실제 플레이 화면의 놀란 동료·상사 얼굴도 함께 확인한다. 충돌체·키·관절 피벗·걷기/접근/제지 수치는 유지하며, 새 Blender 모델이나 외부 캐릭터 팩을 사용한 작업은 아니다.

### v0.2.2의 여성 직원 두 명 — D022 적용과 제작 기준

사용자는 기존 직원 두 명을 여성으로 바꾸도록 요청했다. **이 사원·정 인턴이라는 대상 선택과 아래 머리·얼굴·옷의 구체 구성은 제작 판단**이다. 두 인물은 기존과 같은 허구의 성인 직장인이며, 성격·직급·업무·반응 대사를 이어간다.

| 대상 | 추가 외형 기준 | 이어갈 역할 |
|---|---|---|
| **이 사원 · 여성** | 정돈된 단발의 덩어리와 얼굴 옆면을 연결한다. 기존의 각진 얼굴·눈썹 인상과 사무복의 큰 면을 살려 정 인턴과 구분한다. | 타이핑, 일을 떠넘기는 후배의 말투, 잠시 굳었다가 피하는 반응 |
| **정 인턴 · 여성** | 묶은 머리와 좁은 턱을 구분 가능한 실루엣으로 만든다. 주황색 옷·인턴 출입증·서류 소품을 유지한다. | 서류 확인, 일을 쉽게 안다는 말투, 서류를 든 채 굳었다가 피하는 반응 |

D012의 과장된 성인 체형, 얕은 눈과 움직이는 눈꺼풀, 각진 얼굴·의상 면, 무광 표면을 함께 유지한다. 김 팀장·박 대리·최 과장의 기존 외형과 첫 장면을 기준으로 두 인물의 크기와 그림체를 맞춘다. 충돌체·키·관절 피벗, 업무와 피격·회피 동작은 기존 구조를 사용한다.

두 여성 배역을 실제 게임 모델에 적용했다. 같은 조건의 전후 렌더에서 김 팀장·박 대리·최 과장의 PNG는 바이트 단위로 동일하다. 실제 사무실에서 카메라만 옮긴 검수로 여성 배역이 정확히 두 명인 구성, 이 사원의 타이핑·정 인턴의 서류 확인과 기존 대사를 확인했다. 적용한 모델과 이번 검사 근거는 [현재 상태](current-status.md)와 [v0.2.2 빌드 기록](female-cast-build-report.json)에 기록한다.

이후 외형 수정에서도 같은 카메라와 조명의 전신·얼굴·옆면 렌더에서 두 배역의 머리와 얼굴이 구분되는지 확인한다. 실제 업무석의 머리카락이 눈·어깨·서류를 가리거나 관통하지 않는지, 타이핑·고개 돌림·회피 중에도 얼굴과 손이 읽히는지를 검수 기준으로 유지한다. 이번 화면 확인만으로 모든 반응 자세나 최종 Blender 모델·표정 리깅까지 완성한 것으로 취급하지 않는다.

## 3. 시안만으로 확정하지 않는 것

- **뒷모습과 옆모습:** 뒤통수, 머리카락 뒷면, 등·허리의 형태는 추가 설계가 필요하다.
- **하체:** 상사의 다리·발은 가려져 있고 동료의 하체도 일부만 보인다. 정확한 키·다리 비율·신발·걷는 자세는 미정이다.
- **손 구조와 세부 비율:** 원근이 있는 한 장의 이미지에서 팔 길이, 손가락 길이, 접촉 위치를 수치로 확정하지 않는다. 중립 자세와 1인칭 화면을 함께 보며 조정한다.
- **제작 사양:** 최종 메쉬 밀도, 재질·텍스처 구성, 리깅·표정 구현 방식, 물리 반응 방식은 아직 확정하지 않았다. 이미지에 보이는 자세만으로 완성된 게임용 모델이 확보됐다고 간주하지 않는다.

## 4. 실제 3D 검수 기준

검수 화면은 책상·시점 높이·시야각·NPC 위치·조명을 고정하여 수정 전후를 비교한다. 정확한 카메라 수치는 첫 3D 배치에서 기록한다. 필요한 옆·뒷면 검수는 별도로 하되, 최종 판단은 플레이어가 보게 될 화면으로 돌아와 확인한다.

- **인상:** 세부 질감을 끈 상태에서도 넓은 상사와 마른 동료가 구별되는가? 눈썹·턱·안경·자세가 채택 시안의 성격을 유지하는가?
- **손:** 준비·접촉·회수에서 좌우 손이 맞고 손목이 자연스럽게 연결되는가? 팔이 길게 뻗어 보이거나 주먹이 얼굴과 상황을 가리지 않는가?
- **반응:** 업무 중이던 동료의 눈이 충격 직후 커지고 플레이어를 보는가? 상사는 가림막 위로 얼굴부터 나타난 뒤 항의하며 접근하는가? 세 대사가 지정한 순서로 읽히고 서로 겹치지 않는가?
- **조작과 중단:** 연출 중에도 이동·시점·행동이 유지되는가? 반복 내려치기로 도입 대사가 반복되지 않고, 맞거나 쓰러진 인물의 예약 대사가 취소되는가? 새 판에서는 초회 반응이 다시 가능한가?
- **분위기:** 맞거나 넘어지는 순간에도 풍자와 소동의 인상이 유지되는가? 실제 화면과 동작을 확인한 결과만 완료로 기록한다.

이 문서는 **채택 시안과 제작·검수 기준의 연결**이다. 절차적 모델의 첫 게임 통합과 최종 모델·리깅의 완성을 구분하며, 실제 검증된 범위는 [현재 상태](current-status.md)를 따른다.
