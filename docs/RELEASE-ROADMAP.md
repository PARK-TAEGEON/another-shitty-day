## 2. Release-P2 완료 판정 (모두 필수)

1. **싱글 회사 건물:** 사무실 한 층뿐 아니라 구분되는 핵심 공간 2~3종과 계단/엘리베이터 등 연결된 이동. 모든 층의 독립 아트와 완전 오픈월드는 요구하지 않는다. 이동 후 NPC·경비 이벤트가 이어져야 한다.
2. **도입과 NPC:** 회사에서 혼나고 조롱받는 시작, 자유 조작, 기존 책상 첫 B/반복 A 및 박 대리 놀람→김 팀장 빼꼼→항의/접근 **골든 장면 보존**. 책상을 안 쳐도 대체 반응 가능하고 이미 취소된 대사가 나중에 재생되지 않아야 한다.
3. **상황 확대:** 자유 물리 난투·파괴→목격/신고→경비 수색→경찰차 도착 1회성 연출과 경찰 대응. 특수부대/헬기는 저비용 시청각·전술 상황 연출을 우선하며, 복잡한 비행 물리를 필수로 만들지 않는다.
4. **사장 고유 행동:** 최상층에서 사장 1명 E 붙잡기/같은 층 이동·E 놓기. Held를 실제 본 경찰만 새 직접 제압을 주저하고, 시야 상실/피격/해제 뒤 정상 복귀. 벽 관통·E 이중 소비·무적 악용 0. A/B 결말·특별 퀘스트 완료는 필수 아님.
5. **점수:** 기존 Social Damage($) 손실/중복 방지·결과 기록을 그대로 유지한다. 사장 붙잡기·경찰 주저·방망이 시작에 임의 보너스 $를 붙이지 않고 별도 Chaos Score는 Release-P2 필수에서 제외.
6. **테스트:** 실제 Windows의 시작부터 결과/재시작까지 플레이, 기존 회귀 PASS, 치명 진행 불능 0건, 10~15분 자발적 자유 플레이 품질, 대표 화면/영상과 테스트 로그. 인간에게는 타격감·재미 1회 묶음 검수.
7. **상태 보고:** 실제 합격 증거 없으면 `NOT VERIFIED`/`IN PROGRESS`를 유지. 일정 초과 시 완료 처리 대신 위험·범위 제안서를 제출.

## 4. 일정 지연 시 정책

- **품질 게이트를 거짓 PASS로 채우지 않는다.** 날짜는 목표다. 위험은 추정·재현 근거와 함께 즉시 공개하고 우선 범위 압축안을 낸다.
- 압축 순서: 복제 사무층/모듈형 환경, 소수의 고유 구역, 고단계 적의 저비용 연출, 기존 리그/모션·NPC 상태·소품 재사용, 반복적인 제작·테스트 자동화.
- 자유 난동·NPC 반응의 재미, 기존 골든 오프닝, 사장 붙잡기 충돌/해제 안전, 중복 손실/진행 불능, 멀티 실제 권한 충돌 같은 본질적 게이트는 생략하지 않는다.
- 4인 온라인/추가 고급 애니메이션은 조건부. 협동 자체 제외, 정식 출시 콘텐츠 변경, 출시일 변경은 **사용자 결정**으로 남긴다.
- Steam 스토어/인증/출시 행정은 출시 직전에 몰지 말고 2027년 1월부터 준비한다. 등록비·심사·대기 요건은 진행 시 최신 Steamworks 규정 재확인.
- 에이전트는 작업 세션마다 **SHA/변경 파일/테스트 환경·결과/미검증/다음 게이트**를 문서와 PR에 기록한다. 자동으로 백그라운드 작업이 지속된다고 가정하지 않는다.
