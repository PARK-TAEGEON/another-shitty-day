# 게임 UI 최종 시안 (2026-11-19)

**문서 상태:** APPROVED CONCEPT(사용자가 고른 화면 시안) + PROPOSED(점수·수배 별 규칙).
**구현 상태:** 미구현. `game/`의 실제 UI는 아직 v0.2.2 그대로다. 이 폴더는 디자인 기준이며 IMPLEMENTED가 아니다.
**결정 기록:** [`docs/DECISIONS-2026-11-19-UI.md`](../../DECISIONS-2026-11-19-UI.md)

원본은 Claude Design 캔버스 "Another Shitty Day 게임 UI"(소유자 비공개 링크)에 있다.
A(결재 서류)·B(타블로이드)·C(만화 컷) 세 방향 비교 시안, 최종안, 수배 별 애니메이션 4종이 캔버스에 함께 있고, 여기에는 채택된 화면의 원본만 옮겼다.

### 수배 별

- 별 하나 40×40, 5개, 반투명 어두운 알약 배경 위.
- **빈 별과 채운 별의 윤곽을 똑같이** 맞춘다: 바깥 크림색 선 7px + 안쪽 잉크 선 3px. 빈 별 내부는 크림 30%, 채운 별은 주황. (테두리 색이 다르면 채워질 때 크기가 줄어 보인다.)
- 반 개는 별의 왼쪽/오른쪽 절반을 따로 칠한다.

## 애니메이션 사양

### 결과 화면 — 속보 신문 등장 (한 번 재생)

| 시각 | 동작 |
|---|---|
| 0.00 → 0.68s | 신문이 화면 중앙에서 크기 4% → 108%, **7바퀴(−2520°)** 회전하며 날아옴. 감속 `cubic-bezier(0.2, 0.55, 0.3, 1)` |
| 0.68 → 0.85s | 108% → 100%로 착지, 최종 기울기 −1.5° |
| 0.65 → 0.98s | 화면 전체 흰색 번쩍임 (최대 불투명도 50%) |
| 0.91 → 1.24s | "속보" 딱지가 260% → 92% → 100%로 도장처럼 찍힘 |
| 1.24 → 1.63s | 헤드라인 피해 금액이 0 → 118% → 100%로 튀어나옴 |
| 2.60 → 2.99s | 버튼이 18px 아래에서 올라오며 나타남 |

캔버스 시안은 확인용으로 6.5초 반복 재생한다. 게임에서는 한 번만 재생한다.

### 수배 별 — A 도장 쾅

- **증가(반 개 또는 한 개):** 크기 260%, −30° 회전, 투명 → 0.11초 뒤 82% · 0° · 불투명 → 0.08초 뒤 110% → 0.08초 뒤 100%. 착지 순간 별 줄 전체가 약 0.11초 동안 ±5px 흔들림.
- **감소:** 0.09초 동안 125% · −6°로 부풀었다가 → 0.15초 동안 오른쪽 위(+10, −14px)로 튕기며 30%로 줄고 35° 회전, 투명.
- 반 개 단위는 왼쪽 절반과 오른쪽 절반이 각각 이 동작을 한다.

## Godot 적용 메모 (PROPOSED)

- 카드·버튼: `StyleBoxFlat`(border 3–4px, corner radius, `shadow_size = 0` + `shadow_offset`)으로 오프셋 그림자를 재현한다. 공통 `Theme` 리소스로 묶는다.
- 글자 외곽선: `Label`의 outline / shadow 오프셋.
- 신문 회전: 신문 패널은 자동 정렬 컨테이너 밖에 두고 `pivot_offset = size / 2`로 맞춘 뒤 `Tween`(또는 `AnimationPlayer`)으로 rotation·scale·modulate를 위 표대로 재생한다.
- 망점 사진: 흑백 + 망점 셰이더(캔버스에서는 CSS 점 패턴으로 흉내 냈다).
- 별: 같은 윤곽의 빈 별/채운 별 텍스처 두 장 + 반쪽은 영역 자르기(또는 셰이더).
- 신문 기사 문장은 판마다 실제로 일어난 일(쓰러뜨린 사람, 출동 단계, 피해액)로 채우는 템플릿으로 만든다(PROPOSED).
