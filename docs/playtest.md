# DESK BREAKER — 플레이 검수

이 문서의 체크박스는 검수 기준이다. 초기 상태는 전부 미확인이다. 실제로 확인한 빌드와 환경을 기록한 뒤 체크한다.

주요 검수는 M1·M2·M3의 세 번을 목표로 한다. 수정 결과에 따라 같은 단계의 추가 확인이 필요할 수 있다. 사용자는 느낀 점만 짧게 전달하고, 원인 분석과 수정은 에이전트가 맡는다.

## M1 · 손맛과 첫 반응

### v0.1.1 · 이번에 확인할 짧은 장면

새 판에서 F를 한 번 누른 뒤 동료와 상사를 본다. 접근하는 상사는 마우스로 따라 볼 수 있다. R로 다시 시작한다.

- [ ] 옆자리 동료가 놀라서 눈을 크게 뜨고 “왜 그래?”라고 하는 반응이 자연스럽다.
- [ ] 평소 가려졌던 상사의 얼굴이 빼꼼 나오는 순간과 “뭐야 무슨 소리야?”가 읽힌다.
- [ ] “이게 무슨 짓이지?” 뒤 다가오는 동선과 속도가 자연스럽다.
- [ ] 자막의 화자를 구분할 수 있고 책상·손·얼굴과 겹쳐 읽기 어렵지 않다.

**이번 짧은 답변:** 동료의 놀람 / 상사의 빼꼼 / 다가오는 속도 중 먼저 고칠 한 가지. 캐릭터는 시안의 특징을 옮긴 절차적 3D 첫 제작본이다.

### 네 가지 행동

책상을 내려친 뒤 주먹·발차기·던지기를 차례로 사용하고, 주변 인물의 반응을 본다.

- [ ] 마우스 시점과 이동을 바로 이해할 수 있다.
- [ ] 네 행동의 모션과 실제 맞는 순간이 어긋나지 않는다.
- [ ] 책상을 양손으로 쾅 친다는 느낌이 전달된다.
- [ ] 주먹과 발차기의 속도·무게가 다르게 느껴진다.
- [ ] 물건을 집고 던지는 대상과 방향이 예측 가능하다.
- [ ] NPC가 내 행동을 보고 반응했다는 것을 알아볼 수 있다.
- [ ] 카메라 흔들림·큰 소리·화면 가림 때문에 불편하지 않다.

**짧은 답변:** 제일 시원한 행동 / 가장 어색한 행동 / 먼저 고칠 한 가지.

## M2 · 한 판의 흐름

시작부터 제압까지 플레이한 뒤 재시작한다. 다음 판에서는 다른 물건과 행동을 사용한다.

- [ ] 잔소리가 반복 플레이를 답답하게 만들지 않는다.
- [ ] 작은 소동이 커지는 단계를 장면에서 알아볼 수 있다.
- [ ] 모든 직원이 같은 반응을 보이지 않는다.
- [ ] 경비와 경찰의 개입이 판의 상황을 바꾼다.
- [ ] 점수가 오르는 이유를 대체로 이해한다.
- [ ] 너무 긴 무행동 구간이나 계속 조작을 빼앗기는 구간이 없다.
- [ ] 제압과 결과 화면이 명확하고, 재시작이 빠르다.
- [ ] 다른 방식으로 한 판 더 해보고 싶다.

**짧은 답변:** 지루해진 시점 / 기억나는 사고 한 장면 / 다시 하고 싶은 정도와 이유.

## M3 · 최종 사용성

가능하면 에디터가 없는 환경에서 배포 패키지를 실행한다.

- [ ] 안내된 방법으로 실행되고 화면·입력·소리가 정상이다.
- [ ] 조작 안내와 한국어 UI가 읽히고 겹치지 않는다.
- [ ] 일시정지·재시작·종료를 찾기 쉽다.
- [ ] 음량·마우스 감도 등 제공된 설정이 실제 동작한다.
- [ ] 설정과 최고 기록이 종료 후 다시 실행해도 유지된다.
- [ ] 여러 판을 연속으로 플레이해도 이전 판의 물건·점수·NPC가 남지 않는다.
- [ ] 물건과 NPC가 많은 상황에서도 플레이에 큰 지장이 없다.
- [ ] 임시 자산·알려진 문제·확인하지 못한 사항이 완료 보고와 일치한다.

**짧은 답변:** 공개를 막는 문제 / 지금 품질에 대한 판단 / 남겨도 되는 작은 아쉬움.

## 문제를 발견했을 때

```text
빌드/커밋:
한 행동: 예) 컵을 집고 벽 가까이에서 던졌다.
기대한 반응:
실제 반응:
다시 발생하는지:
영상·화면 또는 로그가 있으면 위치:
```

정확한 기술 용어는 필요 없다. “손이 늦게 나온다”, “의자가 풍선 같다”, “경찰 오기 전이 심심하다”처럼 관찰한 그대로 적으면 된다.
