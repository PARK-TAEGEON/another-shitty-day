# 외형·그래픽 개선 제안

이 문서는 v0.2.2의 여성 배역 변경과 별개인 **다음 제작 단계 제안**이다. 아래의 Blender 모델, 새 리그, 표정 변형, 조명 재작업을 이번 빌드에 적용했다는 뜻은 아니다.

## 목표

승인한 풍자 만화형 인상을 유지하면서, 가까운 거리에서도 얼굴과 몸이 자연스럽게 이어지고 움직일 때 성격이 읽히게 한다. 실사 피부, 사실적인 상처, 높은 폴리곤 수 자체를 목표로 삼지 않는다.

캐릭터 수를 늘리기 전에 **상사 한 명과 플레이어 책상 한 구역을 실제 플레이에서 목표 수준까지 완성**한다. 이후 체형이 다른 여성 직원 한 명으로 제작 규칙을 확인하고 나머지 직원에게 확대한다.

## 현재 화면에서 확인한 병목

| 우선순위 | 현재 상태 | 목표 |
| --- | --- | --- |
| 1. 얼굴·몸의 조형 | NPC는 8각 단면과 평평한 면 노멀, 별도 코·귀·옷깃·팔 메시를 조립한다. 가까이서 이음매와 급격한 면 전환이 눈에 띈다. | 코–볼–턱, 목–어깨–소매가 의도적으로 이어지는 게임용 모델. 큰 면은 남기되 연결 부위와 관절은 다듬는다. |
| 2. 표정과 변형 | 눈·입의 크기 변화와 반복 입 모양이 중심이다. 놀람은 보이지만 비아냥·당황·못마땅함의 차이는 제한적이다. | 눈꺼풀·눈썹·입꼬리·턱을 함께 움직이는 표정, 시선이 고개보다 먼저 반응하는 연기, 팔꿈치와 어깨의 자연스러운 굽힘. |
| 3. 조명 | 방향광 그림자는 이미 있다. 다수의 그림자 없는 보조광과 환경광이 넓은 면을 비슷하게 밝힌다. | 창의 주광과 실내 보조광 역할을 나누고, 얼굴과 배경의 밝기 차이 및 물체가 맞닿는 그림자를 확보한다. |
| 4. 첫 책상의 소품 | 컵 손잡이·두꺼운 종이·모니터·가구 모서리가 단순한 도형으로 읽힌다. | 가장 많이 보는 컵·모니터·키보드·서류부터 두께, 모서리, 접합부, 재질을 마감한다. |
| 5. 손과 NPC의 통일감 | 플레이어 손은 NPC보다 면이 부드럽고 재질 반응도 다르다. | 승인한 팔 길이·좌우·시점·접촉 타이밍을 유지하며 얼굴, 옷, 양손이 같은 미술 규칙을 따르게 한다. |

진단 근거: `game/scripts/office_npc.gd`, `hand_model.gd`, `player.gd`, `world.gd`, `prop.gd` 및 저장된 실제 Godot 렌더. 폴리곤 수를 일괄 늘리거나 모든 부품에 외곽선을 추가하는 것은 첫 해결책으로 삼지 않는다.

## 권장 제작 순서

1. **게임 화면의 비교 기준 고정.** 현재 카메라, 팔 길이, 동료와 상사의 위치, 승인된 접근 경로와 연기 타이밍을 유지한다. 새 모델과 새 조명을 동시에 바꾸기 전에 모델만 비교한다.
2. **상사 한 명의 제작 자료 정리.** 승인 시안을 바탕으로 정면·측면·후면과 평상시/놀람/잔소리/피격 표정을 정의한다. 동일 인물의 일관성을 확인하며 레퍼런스 생성을 끝낸다.
3. **게임용 모델과 몸의 뼈대 제작.** Blender에서 이어지는 형태, 관절 변형, 표정 변형을 마감한다. 기존 행동 코드는 유지하고 새 모델의 뼈대·표정에 연결한다.
4. **실제 플레이 장면으로 검수.** 업무 → 책상 내려치기 → 동료 놀람·상사 빼꼼 → 접근·잔소리 → 피격을 15~20초 정도의 고정 장면으로 확인한다. 정지 이미지뿐 아니라 옆얼굴, 굽힌 팔꿈치, 고개 회전, 양손과의 크기 관계를 본다.
5. **책상 주변과 조명 마감.** 대표 소품 몇 개와 창·실내 조명을 맞춘다. 파손 상태, 충돌, 던지기, 피해액 연결도 보존한다.
6. **다른 체형에서 재현 확인.** 여성 직원 한 명을 같은 기준으로 제작한 뒤 남은 직원·사무실 영역으로 확대한다. 인원 증가는 동선·반응 중첩·충돌·성능 확인을 동반한다.

## AI와 제작 도구의 역할

| 작업 | 권장 방식 |
| --- | --- |
| 디자인 명세, 일관된 참조 자료, 반복 소품, 재질 변형 | AI가 제작과 반복을 맡고 사용자는 비교 화면의 인상과 방향을 검수한다. |
| AI 3D 생성 | 후보 모델이나 단순 소품의 시작점으로 사용한다. 최종 캐릭터는 실루엣, 연결 상태, 관절, 표정을 실제 게임에서 점검한다. |
| Blender 작업 | 스크립트로 생성·정리·내보내기를 자동화할 수 있다. 얼굴 조형과 자연스러운 관절 변형은 자동화 성공을 가정하지 말고 결과로 판단한다. 사용자가 Blender 전체를 직접 배울 필요는 없다. |
| 걷기·대기 같은 공통 동작 | 필요할 때 Mixamo 등의 기본 동작을 출발점으로 삼아 현재 체형과 이동 속도에 맞춘다. |
| 책상 내려치기·빼꼼·잔소리 같은 대표 연기 | 기존에 승인한 동작의 타이밍·접촉을 기준으로 직접 편집하고 새 모델에 맞춘다. |
| 엔진 연결·반복 변형·검증 | AI가 파일 연결, 행동·표정 연결, 비교 영상과 실행본 제작을 맡는다. |
| 반복해도 조형 기준에 못 미치는 구간 | 필요할 때 캐릭터 1명과 리그 또는 1인칭 손처럼 범위가 명확한 부분만 3D 작업자에게 맡기는 대안을 비교한다. 외주·구매는 이번 변경에 포함하지 않는다. |

권장 전달 형식은 **Blender → `.glb` → Godot**이다. 현재의 개별 도형 조립 모델을 그대로 자동 리깅에 넣어 완성될 것으로 기대하지 않는다. Mixamo는 깨끗하게 연결된 이족 보행형 모델과 중립 자세에 제약이 있고, Meshy도 다리의 융합이나 좋지 않은 면 구성은 리메시가 필요할 수 있다고 안내한다.

## 조명과 렌더러

현재 Compatibility 렌더러에서 주광·보조광, 재질의 거칠기, 접촉 그림자를 먼저 비교한다. 렌더러 변경 자체를 품질 개선으로 간주하지 않는다. 고급 효과가 필요해질 때 목표 PC에서 화면과 비용을 확인한다.

고정된 벽·바닥에 간접광을 미리 계산하는 방식은 후속 후보가 될 수 있다. 다만 현재 사무실은 실행 중 생성되므로 빛을 구울 수 있는 장면/UV 준비가 필요하다. NPC와 움직이거나 부서지는 물건은 실시간 조명·그림자 대상이며, 옮긴 물건의 옛 그림자가 남지 않도록 정적 영역과 분리해야 한다. 이번 빌드에는 새 LightmapGI를 적용하지 않았다.
