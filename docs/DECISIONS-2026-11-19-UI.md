## A. 승인된 UI 방향 (APPROVED CONCEPT)

1. **전체 스타일은 C(만화 컷)** — 굵은 잉크 외곽선, 크림색 카드, 블러 없는 오프셋 그림자, 주황·청록 강조, Jua 계열 둥근 글꼴. 툰 셰이딩·외곽선 캐릭터와 맞춘다.
2. **플레이 HUD**
   - 좌상단: **플레이 점수**를 크게, 그 아래 작게 **누적 피해액($)**.
   - 우상단: GTA식 **수배 별 5개, 반 개 단위**. 별 밑 단계 이름 자막은 두지 않는다.
   - NPC 대사는 B(타블로이드)의 하단 뉴스 자막 구성을 C 스타일로(화자 딱지 + 흰 자막 판).
   - 하단 상시 조작 안내 없음(기존 원칙 유지), 조준점 아래 작은 집기 안내 유지.
3. **수배 별 애니메이션은 A "도장 쾅"** — 증가는 크게 기울어진 별이 쾅 찍히며 별 줄이 흔들림, 감소는 부풀었다 튕겨 날아감. 빈 별과 채운 별의 외곽 크기를 동일하게 한다.
4. **일시정지** — C 스타일, 설정과 조작법을 한 화면에 나란히, 상단 상태 줄(점수·피해액·별), 조작법은 괘선 표.
5. **결과 화면** — B의 신문 1면 구성을 **흑백 신문**으로(제호·괘선·명조 헤드라인·기사·망점 사진·괘선 피해 표). **선택 버튼만 기존 색**(주황/흰색). 뒤 배경 게임 화면은 그대로.
6. **결과 화면 등장 연출** — 신문이 빠르게 7바퀴 돌며 날아와 착지 → 번쩍임 → "속보" 도장 → 금액 튀어나옴 → 버튼은 늦게(약 2.6초) 등장.
7. **엔진** — 연출 구현을 위해 엔진을 바꾸지 않는다. Godot 유지(Tween/AnimationPlayer로 충분).

## C. 아직 정하지 않은 것 (PROPOSED)

1. **점수 규칙** — 제안: 쓰러뜨리기, 연속 타격, 던져서 맞히기, 출동 단계 돌파 등 행동 기반 점수. 시간 경과 자동 적립, 임의 배율은 피한다. 결과 화면에 점수와 피해액을 둘 다 표시.
2. **수배 별 단계** — 제안: ★ 팀장 주목 · ★★ 경비 호출 · ★★★ 경찰 출동 · ★★★★ 경찰 증원 · ★★★★★ 특공대. **반 개 = 같은 단계 안의 강도 상승**(예: 경비 1명 → 2명), **한 개 = 출동 주체 변경**.
3. **결과 신문 기사** — 판마다 실제 사건으로 채우는 문장 템플릿.
4. 폰트 5종(Jua, Gothic A1, Noto Serif KR, Nanum Myeongjo, UnifrakturMaguntia)의 게임 반입과 라이선스 파일 동봉.
