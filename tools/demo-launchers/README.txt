Another Shitty Day - Kim / Office Scenario v0.3 integration

압축을 푼 후 AnotherShittyDay-KimDemo.exe를 실행하세요.
기본값: 새 김 팀장 모델, 강한 발차기 한 번으로 래그돌.
비교할 때 실행 중인 게임을 닫고 아래 파일 중 하나를 실행하세요.

01-New-Kim-One-Kick.cmd : 새 모델, 강한 발차기 1회 넉다운
02-New-Kim-Health-Only.cmd : 새 모델, 기존 체력 기준 (체력 40 / 발차기 28 → 2회)
03-Legacy-Kim.cmd : 기존 절차적 모델과 기존 체력 기준

WASD 이동 / 마우스 시점 / Shift 달리기 / F 책상 내려치기
왼쪽 클릭 주먹 또는 들고 있는 소품 던지기 / Q 발차기
E 소품 집기·놓기 또는 사장 붙잡기·놓기 / R 새 판 / Esc 설정·일시정지

김 팀장은 시작 사무실의 상사이며 임시 사장실의 사장과 다른 인물입니다.
박 대리 놀람 → 김 팀장 빼꼼 → 접근 → 잔소리를 보려면 첫 F 후 기다리세요.
쓰러진 김 팀장은 자동으로 일어나지 않습니다. R로 새 판을 시작하세요.
비교 옵션은 실행 단위이며 저장된 게임 설정을 수정하지 않습니다.
나머지 직원 네 명·타 부서 두 명·사장 모델은 기존 상태를 유지합니다.

사람이 확인할 항목:
1. 새 모델의 얼굴·실루엣과 빼꼼·접근·손짓이 자연스러운가?
2. 한 번의 강한 발차기로 쓰러지는 것과 체력 기준 중 어느 쪽이 더 재미있는가?
3. 가구 접촉·낙하·반복 타격에서 불편한 관통이나 심한 떨림이 있는가?
4. 10~15분 자유 플레이와 사장 잡기·경찰 대응·결과·R 재시작이 만족스러운가?

최종 아트/타격감/장시간 성능은 사람 검수 전입니다.
자동 검사와 자동 입력 영상은 인간의 재미 승인으로 간주하지 않습니다.
라이선스 고지는 licenses 폴더를 참조하세요. main 미병합 검수 빌드입니다.
