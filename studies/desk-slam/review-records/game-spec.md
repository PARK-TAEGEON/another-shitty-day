# DESK BREAKER — 게임 규칙

상태: 2026-10-11 제작 기준 초안. 아래 내용은 목표이며, 구현·검증 완료를 뜻하지 않는다.

## 한 문장

평범한 사무실에서 책상을 쾅 친 순간 시작된 소동을 점점 키우고, 제압될 때까지 점수를 올리는 짧은 1인칭 3D 아케이드 게임.

## 첫 완제품의 범위

| 항목 | 기준 |
|---|---|
| 플랫폼 | Windows, 키보드와 마우스 |
| 엔진 | Godot 4, GDScript. 정확한 버전은 저장소의 실행 안내에 고정 |
| 공간 | 사무실 한 곳과 연결된 작은 복도 |
| 등장인물 | 가상의 성인 직원·상사·경비·경찰 |
| 한 판 | 3~5분을 목표로 조정. 강제 제한시간은 현재 확정하지 않음 |
| 종료 | 제압 → 결과·최고 기록 확인 → 즉시 재시작 |
| 표현 | 풍자 만화형 성인 직장인과 통일된 사무실, 과장된 타격·물리 코미디(D010). 실제 모델의 상세 디자인은 후속 제작·검수 |

오픈월드, 여러 맵, 멀티플레이, 장비 성장, 장편 스토리는 첫 버전 범위에 포함하지 않는다.

## 한 판의 흐름

1. 자기 자리 근처의 평범한 사무실에서 시작한다.
2. 상사의 짧은 잔소리가 들린다. 대사 중에도 행동할 수 있다.
3. 책상을 내려치거나 물건을 던지면 주변이 멈칫하고 플레이어를 본다.
4. 직원의 항의·회피·구경이 서로 다르게 나타난다.
5. 소동이 커지면 경비, 이후 경찰이 개입한다.
6. 플레이어가 제압되면 한 판이 끝나고 바로 다시 시작할 수 있다.

첫 행동을 책상 내려치기로 강제하지 않는다. 다만 시작 위치와 집기 배치로 자연스럽게 유도한다.

## 네 가지 행동

| 행동 | 플레이어가 느껴야 할 차이 | 주변 반응 |
|---|---|---|
| 주먹질 | 빠르고 짧은 사거리 | 맞은 물건·인물이 즉시 반응 |
| 발차기 | 주먹보다 큰 밀어내기와 긴 회수 동작 | 의자·작은 집기를 밀거나 인물을 비틀거리게 함 |
| 집어 던지기 | 주변 물건을 골라 사고를 만들 수 있음 | 충돌·낙하·쓰러짐이 눈에 보임 |
| 책상 내려치기 | 양손으로 쾅 내리치는 강한 동작. 초회 연출 B / 반복 조작 A 방향(D009) | 가까운 집기가 흔들리고 주변인이 돌아봄 |

여기서 ‘샷건’은 한국어 구어의 **양손 책상 내려치기**를 뜻한다. 총기 동작으로 해석하지 않는다. 실제 키 배치는 저장소의 조작 안내와 게임 입력 설정을 일치시킨다.

공격은 보이는 동작과 판정 순간이 맞아야 한다. 집은 물건이 벽을 관통하거나, 던지는 즉시 플레이어 몸에 걸려서는 안 된다.

## NPC와 상황 확대

일반 직원의 기본 반응은 `쳐다보기`, `항의하기`, `피하기`, `구경하기`다. 모든 직원이 동시에 적이 되어 돌진하지 않는다. 가까운 사건에 먼저 반응하도록 한다.

| 단계 | 장면에서 확인되는 변화 |
|---|---|
| 일상 | 사람들이 자기 자리에서 일하고 짧은 대화가 들림 |
| 주목 | 가까운 사람들이 행동을 멈추고 플레이어를 봄 |
| 소동 | 항의하거나 도망치는 사람이 생기고 인접 공간까지 반응이 번짐 |
| 경비 개입 | 상황을 진정시키려는 NPC가 들어와 플레이어에게 압박을 줌 |
| 경찰 개입 | 더 큰 압박 속에서 마지막 점수를 노리게 됨 |

정확한 단계별 조건·인원·체력·공격 간격은 플레이테스트로 조정한다. 개입 단계는 적의 체력 증가만으로 표현하지 않는다. 첫 판에서는 새로운 반응과 개입을 알아볼 수 있어야 한다.

## 점수와 실패

- 의미 있는 충돌·파손·쓰러짐에 기본 점수를 준다.
- 같은 접촉이나 같은 쓰러짐으로 점수를 무한히 얻지 못하게 한다.
- M2에서 소동 단계에 따른 배율과 다양한 행동의 보너스를 검토한다.
- 생존 시간만으로 높은 점수를 얻는 구조는 피한다. 계속 행동할 이유가 있어야 한다.
- 제압 이후에는 공격·점수 증가를 멈추고 결과 화면으로 전환한다.
- 재시작하면 NPC, 집기, 점수, 소동 단계가 새 판 상태로 복구된다.

## 경험의 우선순위

1. 입력 직후 손·발·물건·소리가 함께 반응한다.
2. 평범한 사무실이 내 행동 때문에 달라졌음을 알아본다.
3. 한 판을 끝내고 다른 물건으로 다시 사고를 내보고 싶다.

첫 검수는 위 1~2를 짧은 공간에서 확인하는 M1이다. 전체 개입·제압 루프는 M2에서 검수한다.
