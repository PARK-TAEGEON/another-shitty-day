# Desk-slam motion study v3

사용자의 “왼팔·오른팔이 반대쪽에 있는 것 같다”는 피드백을 반영한 **3D 모션 검토본**입니다. 자동 재생으로 `첫 동작 B → 이후 A → A` 순서를 보여줍니다. 플레이어 입력에 연결한 게임 빌드는 아닙니다.

## 이번 수정

- 실제 손 기하의 좌우를 교정했습니다. 로컬 `+Y`가 손끝, `+Z`가 손등인 좌표계에서는 오른손의 엄지가 `-X`, 왼손의 엄지가 `+X`에 있어야 합니다. v2는 이 정의가 반대였습니다.
- 손목의 배치 축도 함께 교정해 **플레이어 왼손이 화면 왼쪽, 오른손이 화면 오른쪽**에 놓이며 손바닥은 몸 안쪽, 손등은 바깥쪽을 향합니다. 엄지는 위에 남고, 새끼손가락 쪽이 책상에 닿습니다.
- 손등 축이 바뀐 데 맞춰 소매의 팔꿈치 곡선을 반대 로컬 축으로 재표현했습니다. v2의 짧아진 팔 실루엣과 바깥으로 굽힌 팔꿈치는 유지합니다.
- 손목 위치, 타격 높이, 모션 타이밍, 카메라 시야각 62도, 장면, 소품 반응과 합성 충격음은 v2에서 유지했습니다. 전체 화면을 좌우로 뒤집은 영상이 아닙니다.

## 아트 방향

사용자는 **풍자 만화형 직장인** 방향을 채택했습니다. 앞선 사실적 인물 콘셉트 A/B는 미채택 상태입니다. 이번 영상의 손은 기존 절차적 모델이며, 선택한 풍자 만화형의 최종 캐릭터·손 아트를 제작하거나 적용한 결과는 아닙니다.

## 타이밍

30 fps 기준입니다. 원본 A 20프레임, B 28프레임을 유지했습니다.

| 동작 | 시작 | 준비 | 내려침 | 접촉 유지 | 복귀 | 전체 |
|---|---:|---:|---:|---:|---:|---:|
| 첫 B | 1.0초 | 8f | 3f | 4f | 13f | 28f / 0.933초 |
| 이후 A | 3.2초 | 6f | 3f | 2f | 9f | 20f / 0.667초 |
| 이후 A | 5.4초 | 6f | 3f | 2f | 9f | 20f / 0.667초 |

영상 길이는 8초이고 접촉 프레임은 41 / 105 / 171입니다. 각 접촉 시점에 같은 충격음이 들어갑니다. 수치는 제작 제안값이며 다른 게임에서 추출하지 않았습니다.

## 파일

- `renders/motion-sequence-v3.mp4`: 연속 모션 영상, 960×540, 30 fps.
- `renders/rest.png`, `intro-lift.png`, `intro-contact.png`, `intro-recover.png`: 첫 B의 대표 프레임.
- `renders/repeat-lift.png`, `repeat-contact.png`, `repeat-recover.png`: 반복 A의 대표 프레임.
- `renders/motion-study-v3-manifest.json`: 타이밍·제작 방식·제한사항.
- `renders/verification.json`: 실제 실행·검사 결과.

## 실행과 렌더

Godot 4.7.2에서 `project.godot`을 열면 자동 순서가 반복됩니다. Python 3와 FFmpeg가 있으면 아래 명령으로 PNG와 MP4를 다시 만듭니다.

```sh
python3 render_study.py --godot /path/to/godot
```

Linux에서 화면 서버가 없다면 동봉한 도구에 Xvfb 의존성 경로를 지정합니다.

```sh
python3 render_study.py --godot /path/to/godot --display-runner tools/with_display.py --xvfb /path/to/Xvfb --xauth /path/to/xauth --library-dir /path/to/x11/libs
```

기존 PNG에서 인코딩만 다시 하려면 `--skip-render`를 사용합니다. 실제 프로젝트 창에는 오디오가 재생되지 않으며, MP4 인코딩 때 합성 충격음을 추가합니다.

## 검증 범위와 한계

검사 결과는 `renders/verification.json`에 기록합니다. 손·팔은 절차적 메시와 자세 보간으로 만든 검토용 모델이며, 본 리깅이나 최종 게임 아트가 아닙니다. 주먹 조이기는 작은 형태 변화이며 손가락 관절의 실제 굽힘을 구현한 것은 아닙니다. 소품 반응은 스크립트 응답입니다. 플레이 입력감, NPC 반응, Windows 실행이나 목표 PC 성능은 이 자료에서 검증하지 않습니다.

장면과 모션·효과음은 원본 제작물입니다. UI 폰트는 Nanum Gothic이고 라이선스는 `assets/OFL.txt`에 있습니다. 기존 `motion-study-v2`와 `desk-breaker`의 게임 코드에는 이 수정 사항을 적용하지 않았습니다.
